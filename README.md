## Running locally

This is a dependency-free static site.

You can open `index.html` directly in a browser, or serve the repository with any simple local HTTP server.

For example:

```bash
python3 -m http.server 8000
```

Then open:

`http://localhost:8000`

## GitHub Pages

The site is deployed from the `main` branch using GitHub Pages.

After pushing changes to `main`, GitHub Pages automatically publishes the updated static site.
